Roboto Mono variable weight font, used only by the browser fixture for real variable-font output.

Source: [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/robotomono), downloaded 2026-10-16. The file is `RobotoMono[wght].ttf`, renamed `RobotoMono-wght.ttf` for local URLs. Its `wght` axis runs from 100 to 700.

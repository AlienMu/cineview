# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security fixes.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use a GitHub
private security advisory for this repository with the affected version,
reproduction steps, impact, and any proposed fix.

We will acknowledge a report within seven days, keep the reporter informed as
the issue is investigated, and coordinate disclosure after a fix is available.

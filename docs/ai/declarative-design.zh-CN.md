# 声明风格与实现约定

设计 Cineview 2.0 声明、增加配置或修改动画实现时，先阅读本约定，让新增功能延续现有的使用方式。内容与视觉设计参照[落地页指南](./landing-pages.zh-CN.md)。[English](./declarative-design.md)

## 版本与实现状态

根目录包和 [DESIGN.md](../../DESIGN.md) 描述 1.0.1 React 实现。本地 2.0 使用 `v2/` 下的自定义元素。编写应用示例前，核对[公开类型](../../v2/src/types.ts)、[JSX 属性](../../v2/src/jsx.ts)和对应解析代码。

本文分别记录已实现行为与设计约定。[阈值设计](#阈值设计)中的具名 `threshold` 尚未实现。记录设计方向不代表语法已经可用，也不代表授权修改运行时。应用能使用什么，以当前源码和公开类型为准。

## 元素

2.0 共有七个元素。`<cv-stage>` 包含所有场景，并决定输入方式（`scroll` 或 `drag`）。`<cv-scene>` 是一个场景，有自己的时间线。`<cv-animate>` 为一个元素声明它在这条时间线上的效果。`<cv-stack>` 把子元素作为卡片叠放。`<cv-video>` 接受 `cv-animate` 的全部属性，另有 `src`、`poster`、`range`（映射文件中的哪几秒）和 `preload`；它的播放时间跟随场景，内部的 `<video>` 用 `::part(video)` 设置样式。`<cv-fixed>` 让内容在所属场景经过时固定在屏幕上。`<cv-pause>` 是一个开关，用来暂停和恢复按时间播放的动效（入场和循环），以符合 WCAG 2.2.2；读者自己的滚动和拖动不受影响。属性和预设的总表见[设计技能](../../skills/cineview-design/framework.md)。

## 把相关行为放在一起声明

内容保留在 HTML 和普通 CSS 中。元素表达职责，属性表达配置：`cv-stage` 选择输入方式，`cv-scene` 组织内容，`cv-animate` 声明元素的动效和时序。属性名使用 kebab-case。这些名称不替换 1.x React 属性名。

同一行为的相关设置放在一个属性中。新增复合配置涉及多个含义或单位时，优先采用逗号分隔的 `名称:值`。独立职责仍分别声明：`threshold` 决定松手是否翻页，`transition-duration` 决定翻页动画的参考时长。

已有语法继续使用各自规定的分隔符：

| 用途       | 已实现声明                  | 含义                                     |
| ---------- | --------------------------- | ---------------------------------------- |
| 动效列表   | `fx="rise, drift(strong)"`  | 最外层逗号分隔不同动效。                 |
| 预设参数   | `fx="push(in, 20% 30%)"`    | 参数属于预设，两个中心坐标保留为同一项。 |
| 动效区间   | `fx="fade 49% 50%"`         | 空格分隔区间两端。                       |
| 属性声明   | `from="opacity:0; y:24"`    | 分号分隔不同属性。                       |
| 依赖与偏移 | `after="title -150"`        | 在指定入场完成前 150ms 开始。            |
| 当前阈值   | `threshold="0.3 0.15 1000"` | 使用现有速度与距离规则，详见阈值设计。   |

列表按对应语法层级拆分。函数、颜色或 keyframes 值内部的逗号属于该值。复用已有解析工具，不能对含嵌套表达式的配置直接按逗号拆分。新增组合配置不要求同时改写所有已有属性语法。

## 分清内容、进度、动效与时序

先说明哪些内容保留、哪些内容变化，以及完成态如何阅读，再选择进度来源。视觉动效和时序围绕该来源声明。

| 决策           | 声明或职责                                                    |
| -------------- | ------------------------------------------------------------- |
| 页面交互       | Stage 的 `input="drag"` 或 `input="scroll"`                   |
| 进度来源       | Animate 的 `on`，或动效支持的默认来源                         |
| 视觉变化       | `fx`、`from`/`to` 或受支持的自定义动效                        |
| 时序关系       | `duration`、`delay`、`name`、`after`、`at` 及受支持的顺序配置 |
| 布局与保留方式 | Scene 结构、CSS、固定元素和堆叠组件                           |

在已加载本仓库 2.0 模块的页面中，这组声明让说明文字在标题完成前开始出现：

```html
<cv-stage input="drag" transition-duration="800">
  <cv-scene id="intro">
    <cv-animate name="title" fx="rise" duration="950">
      <h1>把页面组织成场景</h1>
    </cv-animate>
    <cv-animate fx="fade, drift(soft)" duration="600" after="title -150">
      <p>为每个元素声明进度来源和时序关系。</p>
    </cv-animate>
  </cv-scene>
</cv-stage>
```

`after` 引用同一 Scene 内的入场，负偏移表示重叠。它安排动画的先后；元素呈现为卡片、注释或其他构图，由布局决定。页面切换距离与元素经过的时间分别计算。drag 确认切换后可以继续完成元素时间；scroll 锁定区在停止滚动时保持对应时间。

同一渲染层中，位移和旋转相加，透明度和缩放相乘。裁剪与同名变量有各自的替换规则。不同进度来源通过独立渲染层组合。检查组合后的中间状态，并为每个输出属性确定负责方。实际组合顺序以[渲染层实现](../../v2/src/render/layers.ts)为准。

`on="clock"` 从 Scene 成为当前场景时按真实时间播放，跟随 Stage 暂停，重入时重播。它的独立时序窗口包含 `after` 与 `at`，不增加滚动区长度；`after` 不能跨输入时间线与独立 clock 时间线引用。普通 scroll 由根元素的可见条件启动整条依赖链，离屏后继也会计时。需要滚到内容时才播放，就为它设置独立根元素。

退场进度仍按模式处理：drag 向前离场时推进声明的退场，向后移动时反向播放入场；scroll 锁定区推进求解后的退场窗口；普通 scroll 在元素离开可见条件时播放退场。显式 clock 动画在 Scene 离场时播放退场。入场中断时，退场从当前显示值开始；返回时取消退场，按对应入场或重播规则恢复。

重叠 loop 使用同一套加乘规则，并保留各自周期；裁切与同名变量仍按声明顺序覆盖。`loop-duration` 必须大于零。loop 属性重叠或多个命名区间共享输出时，使用逐帧求值；属性互不重叠时仍可使用独立原生动画。文字拆分与字轴动画组合时，保留未动画的字体轴和可见文字的完成值。

## 调整数值时保留交互方式

调整距离的配置应保留已选择的松手规则。设置一个字段，不应隐式取消短划判断。确实需要更换判断方式时，将其作为独立的行为变更说明。

继承方式属于每项配置的 API。明确其作用范围、单位、默认值，以及覆盖整组还是只覆盖具名字段。不能假定所有 Scene 属性都继承 Stage：当前 `unit`/`scale` 按组覆盖，动效属性则配置所属元素。

计划中的具名阈值按字段解析，优先级依次为 Scene、Stage、默认值。Scene 只设置 `long` 时，继续使用 Stage 的 `short` 与 `time`。解析与校验需要区分字段省略和显式赋值。

## 阈值设计

实现状态：待实现。2.0 的设计方向是在一个属性中使用逗号分隔具名配置：

```html
<cv-stage input="drag" threshold="short:8%, long:50%, time:300ms">
  <cv-scene id="intro">使用 Stage 配置。</cv-scene>
  <cv-scene id="details" threshold="long:35%"> 只调整长拖距离。 </cv-scene>
</cv-stage>
```

| 字段    | 拟定默认值 | 含义                                         |
| ------- | ---------- | -------------------------------------------- |
| `short` | `8%`       | 短划所需的最小手指净位移，占视口高度的比例。 |
| `long`  | `50%`      | 长拖所需的最小页面实际行程，占一屏的比例。   |
| `time`  | `300ms`    | 计为短划的最长手势时间。                     |

保留同一套短划与长拖判断：时长不超过 `time` 时检查 `short`，超过时检查 `long`。设置 `long:35%` 后，短划规则仍然生效。实现时保留小位移过滤、取消和快速反向保护。是否允许切换与动画速度分别配置。

当前实现未设置 `threshold` 时，仍采用固定的 8% / 50% / 300ms 默认规则。设置现有位置参数 `threshold="0.3 0.15 1000"` 后，改用旧的速度与距离规则，三个值分别为慢速比例、快速比例和松手速度，速度单位为 px/s。这条路径替代短划与长拖分类。具名语法和按字段继承尚未接入解析。参照[拖拽规则](../../v2/src/input/drag-rules.ts)与[松手处理](../../v2/src/input/drag.ts)。

后续实现需要同步修改解析、归一化类型、JSX 说明、示例和迁移说明，明确合法值及错误声明的诊断方式。验证修改 `long` 不影响短划结果，Scene 覆盖后仍继承省略的 Stage 字段。这项 2.0 变更保留 1.x API。

## 处理错误声明与连续修改

在挂载 Stage 前监听 `cv-error`，让 AI 或使用者定位需要修改的声明。生产构建也会从出错元素冒泡发送事件；`detail` 包含 `code`、`message` 和 `element`。

```js
document.addEventListener('cv-error', (event) => {
  const { code, message, element } = event.detail;
  console.warn(code, message, element);
});
```

无法解析的 `at` 报告 `bad-at`，并忽略整个属性。格式错误的 `after`、无法读取的 `loop-duration`、非法显式 `input` 或位置参数 `threshold` 中的非法字段，报告 `invalid-attribute`。语法正确但引用不存在元素的 `after` 报告 `missing-after`。其他有效元素仍会构建。按消息检查回退值：非法 `input` 使用 scroll，无法读取的 `loop-duration` 使用 3000ms。

只要存在 `threshold` 属性，即使为空或格式错误，仍会选择旧的速度与距离规则。非法字段保留回退值，具名配置仍不可用。需要默认短划与长拖规则时，移除该属性。不能把收到错误理解为整个 Stage 被拒绝，或已恢复为未设置属性时的行为。

重建中断已取得控制权的拖动时，会发送一次 `cv-dragcancel`。取消后，键盘或辅助激活产生的 `detail: 0` click 仍可使用。

滚动区高度和 drag 场景布局在停止由框架负责时，恢复先前保存的作者值；具体对应移除滚动区或横向 track、切换输入方式或断开连接。框架使用这些内联属性期间，避免同时修改它们。

`count` 的文本暂时没有有效数字时，显示原始文本；有效数字恢复后重新构建计数效果。移除动效或断开连接会结束观察。

## 明确实现中的负责方

沿用现有职责顺序：

1. 配置变化时解析并归一化声明，处理默认值、作用范围和依赖。
2. 由选定的输入控制器负责页面移动与各 Scene 的元素时间，输入事件向该控制器提交操作意图。
3. 求值共享动画语义，再选择原生或直接写入输出。不同输出保留一致的作者区间边界和完成态。

逐帧值使用现有可变状态与订阅。避免逐帧更新 React、解析配置或求解依赖。几何读取集中在写入之前。支持原生时间线与在合成线程执行是两种结论，性能声明需要实际属性和浏览器测量支持。

列表变化时按身份保留当前 Scene。重新编号不等于导航，不应误发离场或入场事件。当前标记、链接、主题、可访问状态和播报与更新后的列表保持一致。

启动异步工作的负责方也负责结束工作。取消待执行帧、移除观察器和监听器，停止过期的字体、idle 和媒体完成回调。重建后允许新原生动画重新挂载。取消媒体离场时保留相应播放位置和用户暂停状态，旧节点事件不能恢复另一次激活的播放。

## 沿用已有扩展方式

先使用现有动效、CSS 和独立容器。受支持的属性与变量通过 `from`/`to` 配置，可复用动效通过 `defineEffect` 定义，适合浏览器插值的多阶段动画使用 `keyframes(name)`。在 `exit` 或 `loop` 中使用扩展前，核对当前限制。任意 SVG 路径形变需要合适的插值实现。

自定义绘制订阅实际需要的来源，并清理自身工作。`timeline.subscribe` 提供时间类帧；纯 `view`、`page` 或信号元素不会通过该时间 API 暴露位置值。作者内容保留语义和可选择文本。参照[扩展与组合说明](./landing-pages.zh-CN.md#实验中的-v2-注意事项)。

优先复用已有工具并局部修改。出现具体重复职责后再引入抽象。使用明确输入与清理过程，避免增加另一个全局进度负责方。

## 验证与交付变更

生成代码前核对目标版本，并标明拟议语法。设计决定需要对应解析器和公开接口实现后，才能用于应用。后续需求确实需要另一种约定时，说明具体冲突，并将实现决定更新到本文。

通过定向测试检查变更涉及的解析、默认值和继承。共享动画逻辑覆盖 drag、scroll、原生、回退、窄区间、重叠动效和阶跃值。浏览器验收还覆盖反向、取消、重入、动态内容、大幅输入、键盘与滚动条、固定层和并行动画。无法操作的输入路径记录为未验证。

中英文指南保持对应。指南位置变化时更新 AI 阅读索引。任务流程和验收证据保留在 Git 忽略目录，可复用回归测试纳入版本管理。适用命令与复核流程参照[代理约定](../../AGENTS.md)和[自检要求](../../AGENT_SELF_REVIEW.md)。

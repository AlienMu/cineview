# 真机测试

这些页面用来在手机上检查 Cineview：滚动、拖动、视频、刷新和首屏。手机上看到的结果和自动记录的数据（报错、帧间隔、就绪时间、视口变化）会提交到 Mac 上的文件里。

## 准备

1. Mac 和手机连同一个 Wi-Fi。
2. 在仓库根目录运行（会先构建运行时，再启动服务）：

   ```bash
   pnpm device
   ```

   终端会打印一个地址，例如 `http://192.168.5.17:4368/`。
3. 用手机打开这个地址，会看到测试目录。

如果手机打不开地址，在 Mac 的「系统设置 > 网络 > 防火墙」里允许 node 接收连接。

## 要测的浏览器

| 设备 | 浏览器 |
| --- | --- |
| iPhone | Safari；微信里打开（把地址发给自己，在微信里点开） |
| 安卓手机 | Chrome（或系统浏览器）；微信里打开 |
| 电脑 | Firefox（可选，桌面版即可） |

每换一个设备或浏览器，在目录页顶部改一下「会话名」，例如 `iphone13-safari`、`iphone13-wechat`、`pixel-chrome`。结果按会话名分开保存。

## 怎么测

1. 在目录页按顺序打开四个测试：滚动、拖动、视频、刷新与首屏。
2. 每个页面底部有「检查清单」。点开后逐项操作：
   - 看起来正常：点「正常」。
   - 有问题：点「有问题」，在备注里写看到了什么、在哪一步。
   - 测不了（例如不在微信里）：点「没法测」。
3. 测完一个页面点「提交结果」，看到「已提交」再回到目录。
4. 「刷新与首屏」最后一项要在系统设置里打开「减弱动态效果」后再测；测完记得关掉。

不填清单也没关系：页面打开 6 秒后和离开时会自动上报报错和帧率。

## 看结果

```bash
node device-test/summary.mjs
```

它会列出每个会话、每个测试的结果、有问题的项和备注、报错、帧间隔（P95、最长、超过 50 ms 的次数）和就绪时间，并写到 `device-test/results/summary.md`。原始记录在 `device-test/results/<会话名>.jsonl`，这个目录不进 git。

title: 页面位移与元素时间线
eyebrow: DRAG / TIMELINES
---

drag 模式下，页面位移和元素动画可以在不同时间完成。页面位移完成后提交场景切换，元素仍可继续入场。

## 页面位移与元素进度

| 数值     | 表示的内容                   |
| -------- | ---------------------------- |
| 页面位移 | 场景向目标位置移动了多远     |
| 元素进度 | 单个入场或退场动画播放了多少 |
| 松手结果 | 继续前往目标，或返回原位     |

各 Scene 的元素时序相互独立，进入另一个 Scene 不会替换离场 Scene 的元素时间线。

## 计算场景元素总时长

总时长取跟随场景的子元素动画中，最晚的结束时间：

```text
场景元素总时长 = max(累计延迟 + 入场时长)
```

`after` 将前序入场时长计入跟随元素的开始延迟。没有跟随场景的 Animate 子元素时，元素总时长为零，松手后无需续播元素动画；页面位移仍独立完成。

通过各个 Animate 的 `duration`、`timeline.delay` 和 `timeline.after` 配置顺序。

## 将拖拽距离映射到时间

默认 `unit: 'time'`、`scale: 10` 时，每拖动 1% 推进 10ms 元素时间，拖动完整一屏推进 1000ms。

6.5 秒的时间线因此在松手前到达约 15%，剩余动画按实际时间继续播放。需要拖拽比例与时间线比例一致时，使用 `unit: 'percent'`。

较短的动画可以先结束，较长的元素继续入场。详见[手势与阈值](/docs/02-gestures)。

## 场景切换期间

进场 Scene 中带延迟的元素在开始时间之前保持初始帧。松手提交后，动画从当前位置继续；取消时，动画返回初始状态。

离场 Scene 的画面跟随页面位移，反向拖拽会让该位移回退。提交场景切换不会中断仍在入场的元素。

## 读取拖拽回调

| 回调             | 含义                             |
| ---------------- | -------------------------------- |
| `onDragStart`    | 确认方向的手势开始               |
| `onDragProgress` | 拖拽中或取消返回期间的进度       |
| `onDragBlocked`  | 应用配置阻止进入目标场景         |
| `onDragEnd`      | 提交场景切换，包含目标与元素时序 |
| `onDragCancel`   | 已接受的手势返回，未提交切换     |

`onDragEnd` 包含 `elapsedMs` 与 `timelineDurationMs`，描述目标 Scene 在提交时的元素时间线，可据此了解当时还剩多少入场。这两个值不会在提交后继续更新。

具体时机见 [drag 回调](/docs/05-callbacks)，随滚动推进的时序见 [center-lock](/docs/01-centerlock)。

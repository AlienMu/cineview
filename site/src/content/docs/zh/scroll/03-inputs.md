滚轮、触控、键盘与滚动条输入都会更新原生滚动位置。锁定区对这些输入使用相同的防跳过限制。

## 输入与滚动位置

```text
输入 → 主轴像素位移 → 区间限制 → 滚动位置 → 动画进度
```

不超过 0.5px 的位移可能保持当前位置。拖动滚动条时先计算目标位置，再应用相同的区间限制。

## 何时处理输入

CineView 应用位移时，会阻止可取消事件的浏览器默认行为。没有产生有效位移时，默认行为仍可执行。

单次输入跨过锁定区时，可以先停在终点，下一次输入继续进入后续内容。锁定区终点不一定产生零位移，滚动容器的最终边界才限制继续前进。

CineView 外的指针输入和已标记 `defaultPrevented` 的事件会被忽略。键盘焦点规则见[键盘事件监听](#键盘事件监听)。

## 四条路径的差异

| 路径      | 增量来源                                           | 归一化                                                                 | 特殊之处                             |
| --------- | -------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------ |
| wheel     | `direction:'y'` 读取 `deltaY`，`'x'` 读取 `deltaX` | `deltaMode:1`（行）×18；`deltaMode:2`（页）× 视窗跨度；`0`（像素）原样 | capture 阶段 + `passive: false` 绑定 |
| touch     | 相对前一次触摸位置的差值                           | 主轴像素                                                               | 每次移动后更新基线                   |
| keyboard  | 按键映射成固定步长                                 | 见按键步长表                                                           | 两个 handler，语义不同               |
| scrollbar | 拖拽 / 点击轨道算出目标偏移                        | 转换为增量后执行统一边界约束                                           | 轨道聚焦后，方向键使用相同的滚动步长 |

键盘步长为固定值：

| 按键                    | 步长                     |
| ----------------------- | ------------------------ |
| `PageDown` / `PageUp`   | ± 视窗跨度 × 0.86        |
| `Space` / `Shift+Space` | 同 PageDown / PageUp     |
| `ArrowDown` / `ArrowUp` | ± 80px                   |
| `Home` / `End`          | ∓ Infinity（约束至两端） |

## 键盘事件监听

键盘输入包含两套绑定层级：

window 级（捕获阶段）：仅当 `document.activeElement` 为 `body` 或 `documentElement` 时响应，此时焦点未被具体元素捕获。该层级不校验嵌套滚动容器。

容器级（`onKeyDownCapture`）：当焦点处于容器内部时响应，自动识别嵌套滚动容器并优先让路。

两者均包含表单元素豁免规则：所有按键直接交由 `input`、`textarea`、`select` 及 `contentEditable` 元素处理；空格键额外释放给 `button`、`summary` 与带 `href` 的链接等可交互节点。

## 横向模式说明

横向模式有两处需要明确：

- 按键映射保持主轴正向语义（`ArrowDown` 与 `PageDown` 仍对应主轴正向步长）。
- 滚轮仅读取 `deltaX`；垂直滚轮输入产生 0 增量，需使用触控板横向滑动手势或 `Shift + 滚轮`。

详见 [横向 direction: 'x'](/docs/04-direction-x)。

## 嵌套滚动容器优先权

内层滚动容器还能沿输入方向移动时，CineView 将事件交给它。判定使用当前轴向、允许滚动的 overflow 样式，以及大于一个像素的剩余行程。

这项规则适用于滚轮、触控和容器内部处理的键盘事件。

## 程序化滚动与用户输入

`goToScene` 或 `goToZone` 平滑滚动期间，不执行防跳过限制。新的有效滚轮、触摸、按键或滚动条输入会停止平滑滚动，从当前位置继续处理用户输入。

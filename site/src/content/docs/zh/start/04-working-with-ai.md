仓库里有一份给 AI 助手用的设计技能：`skills/cineview-design/`。它让 AI 先和用户商定页面，再写代码。

## 技能做什么

技能的核心是一段规划对话。AI 一次问一个问题，每个问题附上自己的推荐和理由，按这个顺序把页面定下来：

1. 页面给谁看，看完要做什么。
2. 读者要记住的一件事。
3. 手上有哪些素材：视频、照片、截图、文案。
4. 方向和场景数，一般 3 到 7 个场景。
5. 每一幕：要说什么、读者看到什么、怎么滚动、用哪些素材、还缺什么。
6. 风格：字体、配色、动效的节奏。
7. 限制：设备、语言、上线日期。

商定后，AI 给出一张分镜表和一份素材清单，用户确认后才开始写页面。用户说「你定」时，AI 按自己的推荐补全，并标明哪些是它替用户定的。

## 技能里有什么

| 文件 | 内容 |
| --- | --- |
| `SKILL.md` | 入口：先对话，再参考 |
| `conversation.md` | 规划对话的问法和分镜表格式 |
| `framework.md` | 2.0 的元素、属性、预设和规则速查 |
| `styles.md` | 13 种视觉方向，各有字体、配色和动效的参考值 |
| `layouts.md`、`combinations.md`、`pages.md` | 版式、组合方式、整页结构的参考 |
| `video.md`、`images.md`、`type.md`、`line-art.md`、`drawing.md` | 按素材分类的做法 |
| `transitions.md` | 视频和动画的转场 |
| `checks.md` | 交付前的检查：语言切换、浏览器探针、刷新不闪 |

这些内容都是参考和建议，不是固定模板，方便不同的页面做出不同的样子。

## 怎么用

- Claude Code 等支持技能的助手：把 `skills/cineview-design` 放进助手读取技能的目录，或者在项目里链接过去。
- 其他助手：让它先读 `skills/cineview-design/SKILL.md`，再按需要打开其他文件。
- 仓库根目录的 `llms.txt` 是给 AI 的阅读索引，列出了技能和 `docs/ai/` 下的指南。

## 给助手的第一句话

不必一开始就给出完整要求。一句话说明要做什么就可以，例如：

```text
做一个摩托车介绍页，用这句话开头：下班以后，绕远一点回家。
```

AI 会从页面给谁看开始问。素材可以在对话中随时发给它，它会先查看素材，再决定每一幕怎么用。

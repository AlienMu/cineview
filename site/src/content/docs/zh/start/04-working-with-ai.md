仓库里有一份给 AI 助手用的设计技能：`skills/cineview-design/`。它让 AI 先和用户商定页面，再写代码。

## 技能做什么

技能的核心是一段规划对话。AI 一次问一个问题，每个问题附上自己的推荐和理由，按这个顺序把页面定下来：

1. 页面在什么设备上看：手机、电脑，还是两端都要。
2. 页面给谁看，看完要做什么。
3. 读者要记住的一件事。
4. 手上有哪些素材：视频、照片、截图、文案。
5. 页面模式：拖动只用于手机，滚动在哪里都能用。两端都要时，可以做一份滚动页，也可以让同一套场景在手机上拖动、在电脑上滚动。
6. 两三个方向，各自有几幕。
7. 每一幕：要说什么、读者看到什么、怎么衔接下一幕（拖动页里是怎么切换到这一幕）、用哪些素材、还缺什么。
8. 风格：一种视觉风格或品牌本身，颜色可以从素材里取。
9. 限制：语言、动效偏好、上线日期。

商定后，AI 给出一张分镜表和一份素材清单。用户在自己的消息里明确同意分镜之前，AI 不写任何页面文件，这是技能里唯一一条强制规则。用户说「你定」时，AI 按自己的推荐补全，标明哪些是它替用户定的，仍然要等用户同意。

## 技能里有什么

| 文件 | 内容 |
| --- | --- |
| `SKILL.md` | 入口：先讨论再制作，以及文件目录 |
| `conversation.md` | 规划对话的问法和分镜表格式 |
| `styles.md`、`pairings.md` | 16 种视觉风格的气质和选项，以及它们和动效、模式、素材怎么搭配 |
| `motion.md`、`relationships.md`、`handovers.md` | 41 种参考各自表达什么、文字和画面的关系、幕与幕怎么衔接 |
| `drag.md`、`phone.md` | 拖动页、手机页，以及两端都要时怎么设计 |
| `video.md`、`images.md`、`type.md`、`line-art.md`、`colour.md` | 每种素材能表达什么，以及怎么准备 |
| `sources.md`、`ranges.md` | 从产品里找设计的提问清单，以及常见的数值范围 |
| `framework.md`、`drawing.md`、`checks.md` | 制作用的写法、自己画图，以及滚动页和拖动页的检查方法 |

这些都是设计思路和带理由的选项，不是模板，方便不同的页面做出不同的样子。

## 怎么用

- Claude Code 等支持技能的助手：把 `skills/cineview-design` 放进助手读取技能的目录，或者在项目里链接过去。
- 其他助手：让它先读 `skills/cineview-design/SKILL.md` 和 `conversation.md`，再按需要打开其他文件。
- 仓库根目录的 `llms.txt` 是给 AI 的阅读索引，列出了技能和 `docs/ai/` 下的指南。

## 给助手的第一句话

不必一开始就给出完整要求。一句话说明要做什么就可以，例如：

```text
做一个摩托车介绍页，用这句话开头：下班以后，绕远一点回家。
```

AI 会先问页面在什么设备上看，并给出自己的推荐。素材可以在对话中随时发给它，它会先查看素材，再决定每一幕怎么用。

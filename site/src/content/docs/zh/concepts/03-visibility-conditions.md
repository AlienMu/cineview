scroll 模式下不在锁定区（locked zone）内的元素，由可见性条件驱动。它不是「位置映射进度」的连续 scrub，而是布尔判定加按时长补间：条件满足前元素停在初始帧，满足后按自己的 `duration` 自计时播完。

这个区别有两个直接后果：这套判定不会让元素停在半进场的中间态，也不会因为滚动速度快而跳帧。

## 六个相位

| 相位       | 含义                                    |
| ---------- | --------------------------------------- |
| `idle`     | 尚未排上，且永不退场                    |
| `waiting`  | 进场条件已满足，在等 `after` 或 `delay` |
| `entering` | 入场补间进行中                          |
| `entered`  | 入场完成                                |
| `exiting`  | 退场补间进行中                          |
| `exited`   | 退场完成                                |

`idle` 永不退场这条是有意的：从视口下方升进来的元素处于 `idle`，即便它同时满足了底部退场条件也不会被误判成退场。

## 判定几何

判据基于元素相对滚动容器的位置。设 `vh` 为容器高度：

```text
进场条件：relTop >= 0 && relBottom <= vh - enterMargin
退场条件：relTop <= exitMargin  ||  relBottom >= vh - exitMargin
```

进场要求元素完全进入视窗，且底边距视窗底还有 `enterMargin` 的余量。退场是对称的两条：顶边逼近视窗顶（正向滚动从上方离场），或底边逼近视窗底（反向滚动从下方离场）。

`enterMargin` 与 `exitMargin` 是设计 px，按换算基准的 `scale` 折成物理 px 后再比较。默认 50，三级回落：单个 `Animate` 的 `visibility.enterMargin` → 根的 `enterMargin` → 50。因为要过 scale，同一个数值在不同视口宽度下对应的物理边距不同。

## 迟滞重叠区间

进场条件与顶部退场条件在 `relTop ∈ [0, exitMargin]` 区间同时为真。若不做互斥，反向重入时元素穿过这段重叠区间，进退场会在同一批次内连续翻转，视觉上是「元素突然出现、又从头播一遍入场」。

规则是：**两个条件同真时保持当前相位，不发生任何迁移**。进场只在严格高于重叠区间时触发，退场只在严格低于重叠区间时触发。

## 超高元素走另一套判据

元素高度超过 `vh - enterMargin` 时，常规进场条件永远不可能满足（它装不进那个余量）。这类元素改用预备规则：

```text
进场：relTop <= vh / 2        （顶边越过视窗中线）
退场：relBottom <= vh * 0.7   （底边升过视窗 70%）
```

这两条的重叠区间很大，且语义是「元素正在离开」，所以超高元素在重叠区间里退场优先（退场条件为真时抑制进场），与常规元素的「保持相位」相反。

## 无 exitAnimation 就永不退场

**只有声明了 `exitAnimation` 的元素才会退场。** 没声明的元素一旦进场就永久停在 `entered` 终态：滚过视窗顶部或底部都不消失、不重置，`replay` 对它不生效。

这是为了避免「没有退场动画的元素一滚过边界就被瞬间隐藏」。那种情况下退场毫无过渡，回滚入场却有动画，两个方向观感不对称。

「声明了退场」的判定有两条路：解析出非空的退场变体且 `duration.exit > 0`，或者只要作者写了 `exitAnimation` 这个 prop。所以完全不写 `exitAnimation` 才是永不退场；写了 `exitAnimation` 但 `duration.exit: 0` 仍算声明了退场，只是补间时长为 0，表现为瞬时跳变而非停在终态。

## 首屏与首帧的两个特例

**首屏冷启动限制**：场景 0 的元素在首屏关键资产就绪前停在初始帧。这条限制对所有模式生效，非首屏场景不受它约束。另外首屏那一次判定会放宽底部边距，否则一个贴着视窗底部的提示元素永远等不到进场。

**首帧已滚过视窗顶**：若元素在第一次测量时底边已经在视窗上方（`relBottom <= 0`），它被直接揭示为已进场终态，不回放入场补间。刷新后停在页面中部时，上方的元素不会集体重播一遍。

## replay

默认 `true`。它只影响 `exiting` / `exited` → 进场这条迁移：元素退场后再次满足进场条件时是否重播。

对「无 `exitAnimation`」的元素它没有意义，因为那类元素根本不会进入 `exited`。

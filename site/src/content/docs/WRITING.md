# Docs 写作规范（2026-08-28 去 AI 味裁决）

本文件是 `site/src/content/docs` 全部双语页面的措辞真源。探针
`site/scripts/docs-style-probe.mjs` 把「禁词清单」做成回归断言，重写或新增页面
必须先过探针再收口。

## 一句话原则

面向清晰、沉稳的技术受众。行文注重逻辑严密与工程客观性，准确传达「参数配置、运行时行为与异常应对策略」。

## 句式规则

1. 一句话只说一件事。两个分句塞两个事实就拆。
2. 先结论后理由。「zone 里 phase 永远是 idle，别用它判断」而不是先讲状态机再得出结论。
3. 禁止三段八股：不写「症状 / 根因 / 正解」式小标。排错页用两拍：**你会看到什么 → 怎么改**。
4. 禁止否定式绕句：「别把它当作 X 的证据」→ 正面说「它不能说明 X」或直接给正确判据。

## 术语规则

5. **工程语义规范**：避免口语化俚语与过度拟人修辞。
   - 避免粗糙俚语：不使用「写死」（改用「固化为引擎常量」「固定基准」）、「裸写」（改用「直接使用原生」）、「翻车/出事」（改用「产生异常偏移/约束冲突」）、「吞掉」（改用「被事件拦截阻止」）、「抢戏」（改用「帧时间竞争」）、「无量纲数值」（改用「非长度类纯数值属性」）。
   - 避免生硬隐喻与第二人称泛滥：不使用「一棵树/这棵树」（改用「DOM 渲染层级」「组件拓扑结构」）、「共享同一个换算基准」（改用「统一视口缩放映射」「共享单轴响应式尺度」）、「引擎覆盖你的 style」（改用「样式层叠与引擎覆盖规则」）。避免通篇出现「你/你的/替你」，改用客观的架构角色描述（如「开发者声明」「自定义节点」「引擎生命周期」）。
6. **实现词汇不外泄**：`lane`、`轨`、`setPhase`、早退、状态机、发布通道、相等性比较
   这类词只出现在源码注释，不进入 docs 散文。用户可见的表述：
   - 「phase 在锁定区内不触发过渡更新」而不是「scrub 轨不走相位状态机」
   - 「滚动每帧直接驱动画面」而不是「render 轨与 element 轨双轨模型」
7. **中英术语定名一次用到底**：
   - takeover zone → **「锁定区」**（zh）/ **locked zone**（en）。首次出现写作
     「锁定区（locked zone）」，之后全程一个名字。
   - scrub → 「跟随滚动」/ scrubs with scroll
   - 预算 budget → 「时长预算」，首次出现说清「1ms = 1px」再复用
8. **禁词清单**（探针断言，中英文本散文均不含；代码与 API 名除外）：
   - zh：旁路、根因、恒为、落点、收敛（非数学）、原子快照、时间常数、正解、轨道隐喻（轨）、
     门控、驻留、帧擦除、擦洗（scrub 的直译，zh 说「跟随滚动」/「逐帧定位」）、
     硬约束、硬规则、硬边界、硬钳、硬编码（改用「强制规则」「固定基准」「严格约束」）、
     写死、裸写、翻车、出事、吞掉、抢戏、无量纲数值、一棵树、这棵树、覆盖你的
   - en：root cause、bypass、time constant、converge/convergent、atomic snapshot、lane、
     permanently idle（写 "never changes" 或 "stays at idle"）、hijack（用 interception）、
     hard constraint / hard rule / hard boundary（用 strict rule / limit / fixed）、
     hardcode / hard-code / hardcoded、swallow / swallowed、tree（在散文隐喻中）
9. 新增一个术语前自问：删掉这个词，句子还能不能懂？能懂就别造词。
   「原子快照」删掉，写「四个值总是一起更新，不会新旧混搭」，信息一字不少。

## 强调纪律

9.1 **加粗是稀缺资源**：每页散文里 `**…**` 不超过 8 处（探针 structural 断言）。
只给扫读时真正需要一眼看到的东西：默认值的坑、会破坏行为的事实、整页核心结论。
因果链中间的加粗、表格例行加粗、形容词式强调（「大幅变慢」）一律去掉 `**`。
9.2 不写口号句：「正方形永远是正方形，绝不形变」「大就是好」这类修辞直接陈述事实即可。

## 双语对齐

10. zh/en 同名页面逐段对应（结构、小节、表格行），措辞各自地道，不互相硬译。
11. frontmatter eyebrow 两语完全一致（探针断言），组名见 manifest GROUP_LABEL。

## 引用与链接

12. 跨页引用具名链接，不写「见上文/下表」（既有探针规则）。
13. slug 稳定不改；重组只动目录与组定义，URL 不变。

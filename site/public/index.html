更灵活的扩展，给你丰富的想象力

框架没有提供的效果，你可以自己画。Canvas、SVG 或 WebGL 订阅元素的 timeline，就能和页面用同一个进度。右边这台放映机就是这样画出来的：往下滚，碎片一片片飞回原位，拼成放映机，胶片盘转起来，光束渐渐亮起；按住还能拖动，转着看。

const time = document.querySelector('#projector-time');
time.timeline.subscribe((frame) => {
  assemble(frame.progress); // 0 到 1，与页面同一个进度
});

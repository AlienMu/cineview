# CineView Drag Mode Test

这个示例展示了 CineView 框架的 Drag 模式新功能。

## 功能展示

### 场景 1: 基础拖拽
- 展示基本的拖拽切换功能
- 包含淡入淡出、滑动、缩放等动画

### 场景 2: 延迟动画
- 展示不同延迟时间的动画效果
- 演示延迟计算和三点映射

### 场景 3: waitFor 关联延迟
- 展示 waitFor 功能
- 演示动画之间的依赖关系和累加延迟

### 场景 4: 智能阈值
- 展示智能阈值判断算法
- 快速滑动、中速滑动、慢速滑动使用不同阈值

### 场景 5: 双向拖拽
- 展示向上和向下拖拽
- 演示双向拖拽支持

### 场景 6: 边界反弹
- 展示边界反弹效果
- 最后一个场景向上拖拽会有橡皮筋效果

## 运行步骤

### 1. 构建框架

首先确保框架已经构建：

```bash
cd cineview
pnpm install
pnpm run build
```

### 2. 安装示例依赖

```bash
cd examples/drag-mode-test
pnpm install
```

### 3. 运行开发服务器

```bash
pnpm run dev
```

浏览器会自动打开 http://localhost:3001

## 测试要点

1. **拖拽流畅度**: 拖拽时动画应该跟随手指/鼠标流畅移动
2. **延迟效果**: 观察不同延迟时间的动画是否按预期播放
3. **智能阈值**: 尝试不同速度的滑动，观察切换阈值是否合理
4. **回弹效果**: 拖拽未超过阈值时应该平滑回弹
5. **边界限制**: 首屏和尾屏的边界反弹效果
6. **双向拖拽**: 向上和向下拖拽都应该正常工作

## 技术实现

- 使用 Framer Motion 的 `useMotionValue` + `useTransform`
- 声明式动画映射
- 智能阈值算法
- 三点映射实现延迟
- 场景状态机管理

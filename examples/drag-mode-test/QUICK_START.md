# 快速启动指南

## 一键启动

如果框架已经构建过，直接运行：

```bash
cd cineview/examples/drag-mode-test
pnpm run dev
```

## 完整启动流程

如果是第一次运行或框架有更新：

```bash
# 1. 构建框架
cd cineview
pnpm run build

# 2. 安装示例依赖（如果还没安装）
cd examples/drag-mode-test
pnpm install

# 3. 启动开发服务器
pnpm run dev
```

## 访问地址

开发服务器启动后，浏览器会自动打开：
- **本地地址**: http://localhost:3001/

## 操作说明

1. **向上拖拽**: 切换到下一个场景
2. **向下拖拽**: 返回上一个场景
3. **快速滑动**: 更容易触发切换（15% 阈值）
4. **慢速滑动**: 需要拖拽更多才能切换（30% 阈值）
5. **未超过阈值**: 松手后会平滑回弹
6. **边界场景**: 首屏和尾屏有橡皮筋效果

## 性能监控

打开浏览器开发者工具：
1. **Performance 面板**: 查看帧率和性能
2. **Console**: 查看日志输出
3. **Network**: 查看资源加载

## 常见问题

### Q: 拖拽不流畅？
A: 检查浏览器性能，关闭其他占用资源的标签页

### Q: 动画没有播放？
A: 检查控制台是否有错误，确保框架正确构建

### Q: 阈值判断不准确？
A: 尝试不同速度的滑动，观察切换行为

### Q: 边界反弹不明显？
A: 在首屏或尾屏用力拖拽，会看到橡皮筋效果

## 调试技巧

1. **查看拖拽进度**: 在控制台查看 dragProgress 值
2. **查看场景状态**: 观察场景状态机转换
3. **查看动画映射**: 检查 useTransform 的映射值
4. **性能分析**: 使用 Performance 面板录制拖拽过程

# 动画展示说明

## 概述

这个性能测试示例展示了 CineView 框架的所有动画能力，包括：
- 场景级进场/退场动画
- 元素级进场动画
- 持续循环动画
- 图片预加载
- 多种手势交互

## 动画类型

### 1. 场景级动画

每个场景都有独特的进场和退场动画组合：

**进场动画（15种）：**
- `slide-up` - 从下方滑入
- `slide-down` - 从上方滑入
- `slide-left` - 从右侧滑入
- `slide-right` - 从左侧滑入
- `fade-in` - 淡入
- `zoom-in` - 放大进入
- `rotate-in` - 旋转进入
- `flip-x` - 水平翻转
- `flip-y` - 垂直翻转
- `bounce-in` - 弹跳进入
- `blur-in` - 模糊到清晰
- `roll-in` - 滚动进入
- `jack-in-the-box` - 弹簧盒效果
- `elastic` - 弹性效果
- `rubber-band` - 橡皮筋效果

**退场动画（15种）：**
- `slide-up` - 向上滑出
- `slide-down` - 向下滑出
- `slide-left` - 向左滑出
- `slide-right` - 向右滑出
- `fade-out` - 淡出
- `zoom-out` - 缩小退出
- `rotate-out` - 旋转退出
- `flip-x` - 水平翻转
- `flip-y` - 垂直翻转
- `bounce-out` - 弹跳退出
- `blur-out` - 清晰到模糊
- `roll-out` - 滚动退出
- `hinge` - 铰链效果

### 2. 元素级动画

每个场景包含 5-8 个动画元素，使用不同的进场动画：

**18种进场动画：**
- `fade-in` - 淡入
- `slide-up/down/left/right` - 四向滑动
- `zoom-in` - 放大
- `scale-up` - 缩放
- `rotate-in` - 旋转
- `spin` - 旋转
- `flip-x/y` - 翻转
- `bounce-in` - 弹跳
- `blur-in` - 模糊
- `focus-in` - 聚焦
- `elastic` - 弹性
- `rubber-band` - 橡皮筋
- `roll-in` - 滚动
- `jack-in-the-box` - 弹簧盒

### 3. 持续动画

每个场景至少有 2 个元素应用持续循环动画：

**13种持续动画：**
- `pulse` - 脉冲
- `heartbeat` - 心跳
- `wobble` - 摇摆
- `swing` - 摆动
- `tada` - 庆祝
- `wave` - 波浪
- `blink` - 闪烁
- `flash` - 闪光
- `shake` - 抖动
- `shake-x` - 水平抖动
- `shake-y` - 垂直抖动
- `vibrate` - 震动
- `jello` - 果冻效果

## 性能测试特性

### 1. 多元素协调
- 每个场景 5-8 个动画元素
- 不同的延迟时间（400-1200ms）
- 不同的动画时长（500-1000ms）
- 测试动画调度器性能

### 2. 图片预加载
- 每 5 个场景加载一张测试图片
- 使用 Preloader 组件
- 测试图片加载性能
- 展示加载状态和错误处理

### 3. 场景切换
- 25 个测试场景
- 每个场景独特的动画组合
- 测试场景切换流畅度
- 评估内存管理

### 4. 手势交互
- 触摸滑动
- 鼠标拖拽
- 滚轮/触摸板滑动
- 测试手势响应速度

## 性能指标

性能监控器实时显示：
- **FPS**：帧率（目标 60fps）
- **Memory**：内存使用
- **Scene**：当前场景/总场景数
- **Load Progress**：图片加载进度

## 测试建议

### 1. 基础测试
- 顺序浏览所有场景
- 观察动画流畅度
- 检查内存使用情况

### 2. 快速切换测试
- 快速滚动切换场景
- 测试节流机制
- 观察性能稳定性

### 3. 图片加载测试
- 跳转到包含图片的场景（1, 6, 11, 16, 21）
- 观察加载状态
- 测试预加载效果

### 4. 持续运行测试
- 让应用运行 5-10 分钟
- 观察内存是否泄漏
- 检查动画是否降级

## 调试技巧

### 1. 打开浏览器开发者工具
```
Chrome: F12 或 Cmd+Option+I (Mac)
```

### 2. 性能分析
- Performance 标签：录制场景切换
- Memory 标签：检查内存快照
- Network 标签：查看图片加载

### 3. 帧率监控
```
Chrome: Cmd+Shift+P → "Show frames per second"
```

### 4. 渲染层分析
```
Chrome: More tools → Layers
```

## 已知问题

1. **图片加载**：使用外部 API，可能受网络影响
2. **内存峰值**：首次加载所有动画模块时会有内存峰值
3. **移动端**：某些复杂动画在低端设备可能降帧

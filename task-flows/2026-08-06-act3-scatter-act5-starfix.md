## 第三幕：四件事

### A. index 层级问题（真 bug，已用浏览器证伪链定位）

**症状**：正在放大的块被「还没轮到的块」盖住。实测 f=0.10 时 01 号（正在放大、
`z-index: 6`）绘制在 02 号（`z-index: 5`）**之下**。

**根因**：`z-index` 挂在 `.a3-panel` 上，而它上面有**两层各自创建层叠上下文**的祖先
（`.cineview-animate` 与 `Position` 的 wrapper，两者 `transform` 均非 none），
且这两层都是 `z-index: auto` ⇒ 六块实际按 **DOM 序**绘制，DOM 末位恒在最上。
`.a3-panel` 上那个 `zIndex: panels.length - index` 是**死代码**。

**四步证伪链**（`site/scripts/_zpaint4.mjs`，逐层试抬 01 号）：

| 实验 | 结果 |
| --- | --- |
| A 原样（01 正在放大，本应在上） | `["02","01"]` ← **bug 复现** |
| B 抬 `.a3-panel` 的 z 到 9999 | `["02","01"]` 无变化 ⇒ 死 |
| C 抬 `.cineview-animate` 的 z 到 9999 | `["02","01"]` 无变化 ⇒ 死 |
| D 抬 **`Position` wrapper** 的 z 到 9999 | `["01","02"]` ✅ **唯一有效宿主** |

**修法**：z-index 从 `.a3-panel` 移到 `Position` 的 `style`。
`Position.tsx:136` 的 `positionStyle` 是 `{...style, position, left, top, ... }` ——
`style` 先展开且 `zIndex` 不在覆盖列表里，故 `style={{ zIndex }}` 安全生效。
序仍取 `panels.length - index`（先出场的在前 = 推近镜头的主体在前）。

### B. 排列更凌乱（不读成 3 列 2 排网格）

旧数据三列共用 x ∈ {-470, 0, 460}、两排共用 |y| ≈ {128–148, 188–218} ⇒ 读成规整网格。
新数据**六块 x/y 全不相同**，且刻意不共列不共排；另给每块一个静态 `--a3-tilt`
（±0.9°–2.4°）打破「边全平行」的机械感。tilt 是静态 CSS 变量，不进每帧路径。

### C. 大小不一致

旧：`base` 0.62–0.86 且盒宽 356–404 ⇒ **实测渲染宽只有 241–306px，仅 1.27× 跨度**，
所以看起来一样大。新：`base` 0.58–1.02 × 盒宽 300–430 ⇒ 渲染宽 186–439px，**2.36× 跨度**。

### D. 朝中间移动（运动模型第三版）

- v1 向外扩张 —— 用户否掉。
- v2 原位放大（`x/y` 恒 0）—— 本轮用户改口径。
- **v3（本轮）**：放大的同时**朝画布中心平移**，终点落在正中。

`x/y` 由 Animate lane 拥有（在框架 10 属性白名单内），单位用 `vw`：设计画布宽
1440 ⇒ 1 设计 px = 1/14.4 vw，**桌面手机同一把尺**（认宽不认高）。
关键帧与 scale/opacity 共用同一 `times` 轴。

**顺带简化**：终点在正中后，`resolvePeakScale` 的 `reach` 项（按「块心到最远角」反解）
**不再需要** —— 那是为「原位放大」算的。只留 fill 项（把自身撑到盖满画布）。
实测 peak 从 3.66–4.98 降到 3.35–4.30，放大末段的 overdraw 与 blur 面积同步下降。

## 风险

1. **朝心平移 + 六块并发**：v2 的 `x/y` 恒 0 让 lane 只驱动 3 个属性；v3 变成 5 个
   （x/y/scale/opacity/filter）。第三幕此前实测零掉帧、余量充足，但**这是新增每帧代价**，
   S7 必须复测第三幕帧性能，不能只看几何。
2. **tilt 创建层叠上下文**：`.a3-panel` 加 `rotate` 会再建一个层叠上下文 —— 但 z-index
   宿主已移到 `Position` wrapper，两者不冲突。仍需 S7 实测确认 z 序未被 tilt 破坏。
3. **peak 去掉 reach 项后是否真铺满**：终点在正中 ⇒ 理论上只需 fill；但 tilt 让外接盒
   略大于 w×h，故 FILL 取 1.06 留余量。S7 必须实测「铺满画布」而非只信推导。
4. **手机版**：本轮改了 base 跨度与 x 抖动，`2026-08-04-act3-phone-layout.md` 的十档
   窄屏结论（尤其 `--a3-fs` 下限与内容溢出）需重跑 `act3-overflow-check.mjs`。

# act5 黑金改版 frontend-design 审查（2026-08-19）

- 审查对象：首页 scroll 第五幕 Scene5Cinema 黑金改版（星野退役 / 淡黑金渐变 overlay / 双层金雾呼吸 / split 态文案对标手机高度）
- 方法：Playwright 真机（headed 1440×900，`http://localhost:4000/#/`）+ 像素级量化采样 + split 态几何测量。探针：`site/scripts/_act5-gold-review.mjs`、`_act5-gold-pixels.mjs`、`_act5-gold-split-geo.mjs`；截图 `/tmp/act5-review/`。
- 结论：**PASS（4/4 项，零调整必改项；附 2 条可选微调）**。console error 0 条、pageerror 0 条（两轮全流程）。

## 逐项判定

### 1. 淡黑金渐变「淡而不显」 — PASS

满黑段（lightsoff wrap opacity 0.94）背景实测：

| 区域 | 平均 RGB | 暖度 Δ(R−B) |
| --- | --- | --- |
| 右上（主雾 a 方向） | 29.5–32.5 / 25.9–28.7 / 22–23.2 | 7.4–9.3 |
| 左下（副雾 b 方向） | 28.7–30.6 / 25.5–27.2 / 22.5–22.9 | 6.2–7.7 |
| 中部安静区 | 25–30 / 23–26 / 21–22 | 4.6–7.4 |

- 整帧亮度地板 ~26–37/255（近黑但高于 #0a0909 的 10），最热区暖度峰值 ~9–12/255 ≈ 4%——直视是「黑里一层暖」，暗适应后隐约可辨，正是「金色不要太明显」的量级。金色主要读作**色相**（ΔR−B 5–12）而非亮度，不会喧宾夺主。
- 145deg 方向读得出来：顶部条带 ΔR−B 10.4–12.5 > 底部 6.2–7.7，右上暖 → 左下黑的斜向梯度成立（副雾 b 的铜金在左下形成微弱对冲，6.2–7.7 仍低于右上，层次未被抹平）。
- 参数无需改。若未来用户反馈「金的呼吸看不见」，第一杠杆是 a 层 floor 0.55→0.65（收窄摆幅抬高底），而不是加 alpha。

### 2. 金雾呼吸（柔和 / 频率 / 异相） — PASS

infinite lane 驱动的 CSS 变量 → opacity 实测（满黑段三个时刻）：

| 时刻 | a 层 opacity | b 层 opacity |
| --- | --- | --- |
| t0 | 0.773 | 0.894 |
| t+3s | 0.959 | 0.550 |
| t+7s | 0.567 | 0.646 |

- 摆幅 0.55↔1、easeInOut、半周期 4.5s/7s——是环境呼吸节奏，不读作闪烁；换算到像素的暖度摆幅仅 ~±2/255，柔和成立。
- 异相/有机性：t+3s 恰逢 a 近峰、b 近谷（反相时刻），t0 双中位——9s/14s 互质使相位关系持续漂移，不产生合成拍频，读作有机。split 态下呼吸仍在继续（split-final b=0.96 → 4s 后 b=0.55，走完近整周期），「背景持续动画」在终态保持。
- 可选微调（非必改）：若想更「影院片头」的沉缓，周期 9/14s → 11/17s。当前值已合格。

### 3. 熄灯中段 vs 满黑两阶段层次 — PASS

- 中段（wrap 0.417 实测截屏）：底材 ~RGB 147–150、暖度 20–33——明亮场凳内容透出 58%，读作「灯在熄」的过程态。
- 满黑（wrap 0.94）：地板 ~27/255、暖度 5–12——近黑金氛。两阶段亮度差 ~5.3 倍、色温结构不同（中段暖度来自底材内容，满黑暖度来自 overlay 渐变+雾），层次分明，无中间灰浆带。

### 4. split 态四拍 space-between 构图 — PASS（split 第 3 轮拖拽触发成功）

iframe 拖拽（72%→18% 高、24 步）：round 0–2 推进内幕（`cineview-embed-unfinished`），round 3 收到 `cineview-embed-finished` → split。实测几何：

- 手机 45→855（810px = 90.0vh，宽 373.5，332/720 等比保持）；文本列 45→855——**与手机严格等高同轴**（像素级重合）。
- 四拍：45–153.5 / 274.7–369 / 490.1–634.5 / 755.6–855；拍间间隙 **121.2 / 121.1 / 121.1px**——space-between 完全均分，四拍沿手机全高分布，「文案太紧凑」已解。
- 首拍顶边 = 手机顶边（45）、末拍底边 = 手机底边（855）：文字悬挂在手机上下轨线上，是成立的对齐策略。可选微调（非必改）：若想 soften 边缘贴齐感，text-col 加 `padding: 12px 0` 让四拍从轨线内收 12px——纯口味，当前 flush 版本合格。
